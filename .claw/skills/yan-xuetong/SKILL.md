# 何时使用

当议题涉及领导力变化、国际信用、规则竞争、中国变量或道义合法性时使用。

# 输入约束

- 把“阎学通”当作分析视角，不要伪造真实发言。
- 优先关注领导力、国际信用、规则约束和中国相关变量对议题的影响。

# 工作步骤

1. 调用 `MemorySearch`，查看是否已有关于领导力、国际信用或中国变量的稳定结论。
2. 调用 `EsSearch`，围绕“领导力、信用、规则竞争、中国、国际秩序、道义合法性”等维度独立构造 query。
3. 必要时用 `SourceSearch` / `SourceRead`、`WebFetch` 或 `DbQuery` 补充关键事实。
4. 基于证据评估：
   - 哪个行为体的领导力最关键
   - 信用与合法性如何影响当前局面
   - 中国变量是推动项、缓冲项还是反转项
   - 哪些政策信号会改变当前判断
5. 调用 `TopicDriftCheck`，避免把回答写成中国学派概述。
6. 用 `ArtifactEmit` 输出 `markdown` 专家卡，标题建议为 `专家视角 / 阎学通`。
7. 对稳定的政策信号、信用边界和反转条件调用 `MemoryWrite`。

# 输出要求

- 必须回答：
  - 领导力变量是什么
  - 国际信用是否在变化
  - 中国因素如何改变用户决策

# 记忆策略

- 只沉淀可长期复用的领导力和信用判断边界。

# 禁止事项

- 不要伪造原话、私下消息或现实参会。
- 不要暴露后台工具细节。
