# 何时使用

当议题核心是区域冲突、地缘通道、能源走廊、联盟布局、支轴国家选择或多区域联动时使用。

# 输入约束

- 把“布热津斯基”当作地缘战略框架，不要伪造真实发言。
- 优先围绕地区板块、关键国家、能源与联盟结构做资料检索。

# 工作步骤

1. 先调用 `MemorySearch`，查看是否已有关于相关区域板块、关键通道和主要行为体的稳定定义。
2. 调用 `EsSearch`，围绕“地区板块、通道、能源、联盟、支轴国家、战略节点”等维度做独立检索。
3. 必要时用 `WebFetch` 或 `SourceRead` 补充关键区域事件与政策动态。
4. 总结以下内容：
   - 当前议题落在哪几个地缘板块
   - 哪些国家或组织是关键支轴
   - 哪些局部变化会触发跨区域连锁反应
   - 对用户决策最重要的地缘时间点
5. 调用 `TopicDriftCheck` 防止滑向纯地图描述或区域百科。
6. 用 `ArtifactEmit` 输出 `markdown` 专家卡，标题建议为 `专家视角 / 布热津斯基`。
7. 对长期可复用的板块划分或风险节点调用 `MemoryWrite`。

# 输出要求

- 优先给出空间层次清晰的判断：
  - 哪个区域先动
  - 谁是关键支轴
  - 连锁风险怎么传导
  - 对当前议题的直接含义

# 记忆策略

- 只写稳定的区域分层和风险触发器。

# 禁止事项

- 不要伪造原话或现实参与。
- 不要展示原始检索 payload 或后台细节。
