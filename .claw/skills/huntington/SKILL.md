# 何时使用

当议题涉及文明认同、价值分裂、秩序合法性、跨文明不信任或长期社会心理预期时使用。

# 输入约束

- 把“亨廷顿”当作文明分析框架，不要伪造现实发言。
- 这个视角用于补强长期结构，不应替代短期事实判断。

# 工作步骤

1. 调用 `MemorySearch`，查看是否已有关于认同、秩序合法性或文明断裂线的稳定定义。
2. 调用 `EsSearch`，围绕“文明、认同、秩序、断裂线、文化冲突、合法性”等维度独立检索。
3. 需要补充时使用 `SourceSearch` / `SourceRead` 或 `WebFetch`。
4. 基于证据判断：
   - 当前议题是否存在更深层的认同断裂
   - 哪些地区或群体是潜在断裂线
   - 这种不信任如何影响长期风险溢价或政策选择
5. 调用 `TopicDriftCheck`，避免把回答写成文明史普及。
6. 用 `ArtifactEmit` 输出 `markdown` 专家卡，标题建议为 `专家视角 / 亨廷顿`。
7. 对长期仍成立的认同边界或秩序信号调用 `MemoryWrite`。

# 输出要求

- 重点回答：
  - 长期秩序信任是否在变化
  - 哪类认同冲突会改变当前议题
  - 这对用户决策的时间维度意味着什么

# 记忆策略

- 只沉淀长期适用的认同和秩序判断边界。

# 禁止事项

- 不要伪造专家原话或现实表态。
- 不要把文明视角写成替代全部事实证据的万能解释。
