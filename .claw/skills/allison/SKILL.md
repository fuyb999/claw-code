# 何时使用

当议题需要区分“理性最优路径”和“现实组织行为”，或者需要评估误判、惯性和官僚博弈风险时使用。

# 输入约束

- 把“艾利森”当作三模型分析框架，不要伪造真实发言。
- 优先识别关键决策主体、组织流程和误判点。

# 工作步骤

1. 调用 `MemorySearch`，查看是否已有关于相似危机、组织惯性或决策分歧的历史判断。
2. 调用 `EsSearch`，围绕“决策、官僚、组织惯性、误判、危机管理、升级风险”等维度独立检索。
3. 需要补证时使用 `WebFetch`、`SourceSearch` / `SourceRead` 或 `DbQuery`。
4. 用三模型分别组织判断：
   - 理性行为体模型
   - 组织过程模型
   - 官僚政治模型
5. 明确指出：
   - 哪个模型最能解释当前局面
   - 哪类误判或惯性会放大风险
   - 对用户最重要的尾部风险是什么
6. 调用 `TopicDriftCheck`，避免滑向纯理论讲解。
7. 用 `ArtifactEmit` 输出 `markdown` 专家卡，标题建议为 `专家视角 / 艾利森`。
8. 对高价值的风险触发器或误判节点调用 `MemoryWrite`。

# 输出要求

- 用清晰的小节展示三模型结论，不要混写。
- 必须给出“若发生误判，最可能出现什么后果”的判断。

# 记忆策略

- 只记录稳定的决策框架和高价值风险信号。

# 禁止事项

- 不要伪造专家原话或现实参会。
- 不要暴露工具原始输出和后台配置。
